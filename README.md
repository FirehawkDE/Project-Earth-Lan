Project Earth LAN bringt das klassische Gefühl von spontanen LAN-Partys zurück ins digitale Zeitalter. Es verbindet dich und deine Freunde. Egal wo ihr seid: Für eure Spiele sieht es so aus, als würdet ihr alle im selben Raum am selben Switch hängen.

Klick & Play (Installer): Keine komplizierten Netzwerk-Einstellungen. Ein Skript für die Installation, eins für die Deinstallation – der Rest läuft im Hintergrund.

​Sicher & Direkt: Deine Daten fließen direkt von PC zu PC (Peer-to-Peer). Keine Umwege über langsame Drittanbieter-Server.

Kostenlos & eigenes Server Hosting: 

​Du möchtest einen dedicated Server für deine Freunde aufsetzen, hast aber keine öffentliche IPv4-Adresse oder Lust auf teure Server-Mieten?

​Hoste selbst: Lass deine eigenen Gameserver (z. B. C&C, Minecraft, Call of Duty, Terraria, Battlefield, Unreal Tournament) direkt über das Project Earth LAN laufen.

​Kein Port-Forwarding: Kein Stress mit Router-Einstellungen oder CGNAT. Das Netzwerk regelt das Routing automatisch.

​Absolut Kostenlos: Keine Versteckten Gebühren, keine VIP-Ränge. Einfach beitreten, Server starten, loszocken.

​Sauber & Rückstandslos: Wenn du es nicht mehr brauchst, entfernt der Uninstaller das System wieder so spurlos, als wäre es nie da gewesen.

Für wen ist das gedacht?

​Für Casuals: Du willst nach Feierabend einfach nur mit Freunden ein altes Lieblingsspiel zocken, ohne vorher ein Informatik-Studium für Router-Portfreigaben abschließen zu müssen.


Für Gamer & LAN-Nostalgiker: Du suchst eine performante, stabile und saubere Alternative zu überladener Software – maximale Kontrolle, minimale Latenz.
